## Installation
To install the plugin, download the newest [Release build](https://github.com/GraczBezNicku/OverseerAC.Plugin.TrustFactor/releases) and place it in your LabAPI's plugins folder.

## Configuration
The configuration file will be generated on first boot with the plugin installed.

Default configuration:
| Name       | Default Value                   | Description                                                                     |
|------------|---------------------------------|---------------------------------------------------------------------------------|
| TestMode   | `false`                         | When enabled, untrusted players will be marked instead of kicked.               |
| Language   | `english`                       | Determines the language used by the plugin.                                     |
| BaseApiUrl | `https://api.overseerac.eu/v1/` | OverseerAC's base API url. DO NOT EDIT UNLESS YOU KNOW WHAT YOU'RE DOING!       |
| ApiKey     | Empty                           | Your OverseerAC API key. If you want one, read the main repository linked above |
